# Audio assets (production)

Required files for the full Zyra audio experience:

- **click.mp3** – UI click (buttons, nav, dropdowns, links)
- **toggle-on.mp3** – Sound toggle when enabling
- **toggle-off.mp3** – Sound toggle when disabling
- **menu.mp3** – Mobile menu open/close
- **logo.mp3** – Brand loading screen (once per session)
- **ambient.mp3** – Looping ambient layer

All paths are under `/audio/` (e.g. `/audio/click.mp3`). The site degrades gracefully if files are missing.
